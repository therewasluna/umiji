## Метод входа: пароль

### Изменение или сброс пароля

На сервере панели под root введите:

```bash
umiji
```

Выберите пункт `Owner password`. Команда покажет имя пользователя владельца и спросит новый пароль, а если нажать Enter, сама создаст надёжный.

Команду `umiji` добавляет установщик. Если на сервере её нет, запустите установщик ещё раз:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/therewasluna/umiji/main/install.sh)
```

### Экстренное включение входа по паролю

Если вы отключили метод входа "Пароль", а потом потеряли доступ к другим методам входа, `Owner password` заодно снова включает вход по паролю. Задайте с его помощью новый пароль и войдите.
